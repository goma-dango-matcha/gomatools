書類ファイルの種類と違い

クリアホルダー

穴を開けずに書類を挟み、持ち運びや一時整理に使います。

クリアブック・ポケットファイル

複数の透明ポケットへ書類を分け、ページをめくるように確認できます。

フラットファイル

穴を開けた書類をとじ具で固定します。2穴の製品例があります。

リングファイル

リングを開閉し、穴を開けた書類を追加・差し替えできます。

パイプ式ファイル

多くの書類をまとめる用途で使われます。とじ厚や収容枚数は商品ごとに異なります。

ルーズリーフ用バインダー

多穴のルーズリーフを整理します。用紙サイズと穴数の両方を合わせます。

A4用とA4ワイドは何が違う？

  • A4用は、一般にA4用紙を収納するための商品区分です。
  • A4ワイドは、クリアホルダーやインデックスなどを収めやすいよう、余裕を持たせた商品名や区分に使われることがあります。
  • 「ワイド」には共通の固定寸法があるとは限りません。商品の内寸・外寸・対応物をご確認ください。

クリアホルダーごと収納するときの注意

クリアホルダーは、収納する用紙より外寸が大きくなります。A4用紙だけを入れられるファイルや封筒でも、A4用クリアホルダーごとでは余裕が足りない場合があります。

  • クリアホルダーの実寸と、収納先の内寸を確認する
  • 書類の枚数、厚さ、インデックスや付箋の張り出しも考慮する
  • 「クリアホルダー対応」など、商品ごとの対応表示を確認する

補足・注意事項

  • 「A4用」などの表示は、該当する用紙を収納するための目安です。ファイル本体の外寸やポケットの内寸は商品によって異なります。
  • 収納できる枚数は、紙の厚さ、とじ具、リング径、ポケットなどによって変わります。
  • 本ページは一般的な対応関係を整理したもので、特定商品の適合を保証するものではありません。

🍵 ゴマワンポイント

「A4用」と書かれたファイルは、A4用紙を収納できるよう用紙より少し大きく作られています。クリアホルダーやインデックスごと収納するときは、外寸だけでなく内寸や対応物の表示も確認しましょう。

よくある質問

A4用ファイルの大きさはA4用紙と同じですか？

同じとは限りません。A4用紙を収納できるよう、ファイル本体やポケットは用紙より大きく作られています。実際の寸法は商品ごとに異なります。

A4用とA4ワイドは何が違いますか？

A4ワイドは、クリアホルダーやインデックスなどを収めやすいよう余裕を持たせた商品名や区分に使われることがあります。固定された共通寸法ではないため、商品の対応物と内寸を確認してください。

A4は何穴のバインダーを使いますか？

用途によって異なります。一般書類では2穴、ルーズリーフでは30穴などの製品があります。穴数だけでなく、用紙サイズと穴位置も確認してください。

B5は何穴ですか？

B5のルーズリーフでは26穴の製品がありますが、すべてのB5用品が26穴という意味ではありません。商品の対応表示をご確認ください。

クリアホルダーに入れたA4書類はA4用封筒に入りますか？

用紙だけの場合より外寸が大きくなるため、入らないことがあります。封筒の内寸とクリアホルダーの実寸をご確認ください。
