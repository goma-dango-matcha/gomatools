## 1. 目的

「クリアファイル」と「クリアホルダー」の呼び方、形状、用途の違いを短時間で理解できる記事とする。

特定メーカーの商品比較ではなく、書類整理用品を用途に合わせて選ぶための基礎知識を扱う。

---

## 2. 記事の役割

- 日常会話とメーカーの商品分類で呼び方が異なることを説明する
- 袋状のクリアホルダーと、複数ポケットのクリアブック等を区別する
- フラットファイル、リングファイルとの役割の違いを説明する
- A4用商品の外寸と、A4用紙の寸法が異なることを説明する
- 書類ファイル・バインダー対応早見表へ案内する

唯一の正式名称があるような断定は行わない。

## 4. 結論

記事冒頭で次を明示する。

- 同じ薄型の書類入れを指して使われる場合がある
- メーカーによって袋状と複数ポケットの商品を呼び分ける場合がある
- 商品名だけでなく、形状、対応用紙、ポケット数を確認するのが確実

## 6. 用語方針

- 袋状の用品は、一般的な説明では「クリアホルダー」とする
- 「クリアファイル」は袋状の用品と、複数ポケットの商品群の両方に使われる場合があると説明する
- 複数ポケットの冊子状用品は「クリアブック・ポケットファイル」と説明する
- メーカー固有の表記を業界全体の統一名称として扱わない

---

## 7. 比較表

| 項目 | クリアホルダー | クリアブック・ポケットファイル |
| --- | --- | --- |
| 主な形状 | 薄い袋状 | 複数ポケットの冊子状 |
| 収納方法 | 1か所へまとめて入れる | ポケットごとに分けて入れる |
| 向いている用途 | 一時保管、持ち運び、受け渡し | 分類、閲覧、継続的な保管 |
| 穴開け | 不要 | 不要 |
| 注意点 | 書類が混ざりやすい | ポケット内寸・枚数制限を確認 |

表には`caption`と`scope`を設定し、狭幅でも横スクロールを発生させない。

## 8. A4用・A4ワイド・封筒

- A4用クリアホルダーはA4用紙を入れるため、用紙より外寸が大きい
- 商品本体の内寸・外寸・収納量は製品ごとに異なる
- A4ワイドは固定された共通寸法の用紙規格として扱わない
- 封筒へ入れるときは、封筒の内寸とクリアホルダーの外寸を確認する
- 「A4対応」だけを根拠に収納可能と断定しない
