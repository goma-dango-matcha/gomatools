## 目的

A4・B5・A5などの用紙に合う書類ファイル、バインダー、一般的な穴数を、入力せず一覧から確認できるページを提供する。

商品比較や購入案内ではなく、用紙と書類整理用品の一般的な対応関係を確認する早見表とする。

## 重要な表現ルール

- 「A4用」はA4用紙を収納する目安であり、本体外寸・ポケット内寸は商品ごとに異なると明示する
- 「A4は必ず30穴」「B5は必ず26穴」などと断定しない
- 穴数が同じでも穴位置・間隔・向きが異なる場合があると明示する
- A4ワイドを固定された共通寸法や用紙規格として扱わない
- クリアホルダーごと収納すると必要内寸が大きくなることを説明する
- 特定商品への適合や収納可能枚数を保証しない

## 掲載しない内容

- デジタルファイル容量

- 法定保存期間などの法的判断

## 情報源

一次または準一次情報として、国内文具メーカーの公式製品情報・カタログを確認する。

- プラス株式会社：クリアーホルダー、A4ワイド表記の製品例
- コクヨ株式会社：2穴フラットファイル、A4・B5・A5バインダーの製品例
- 株式会社リヒトラブ：クリヤーブックの対応サイズ、クリアホルダー収納対応製品例

商品固有の寸法や仕様を共通規格として一般化しない。
