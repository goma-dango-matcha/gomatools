## 1. 目的

スマートフォン写真をL判などへ印刷すると端が切れる主な理由と、写真全体を残すための対策を初心者向けに説明する。

本記事は写真サイズの寸法一覧ではなく、縦横比、トリミング、余白、撮影・編集・注文時の対策を扱う。
