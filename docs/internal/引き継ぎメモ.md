## 1. サービス概要

- サービス名: ゴマツール
- ブランドコンセプト: **毎日に、一歩便利。**
- サービス説明: 計算ツール、入力不要ツール、ゴマ知識、ゴマ早見表を通じて、毎日の確認や疑問解決を支える無料Webサービス。
- ブランドシリーズ: **計算ツール／入力不要ツール／ゴマ知識／ゴマ早見表**の4シリーズを中心に育成する。ゴマ早見表は、入力せず整理された一覧から必要な情報を比較・確認するシリーズ。
- ブランド育成: 単発のツール集ではなく、使いやすさ・分かりやすさ・安心感を備えた一貫性のあるサービスブランドとして育成している。
- スマホファースト: 小さな画面でも主要情報へすぐ到達でき、迷わず操作できる構成を優先する。
- タイパ重視: 短時間で答えが分かり、必要な場合だけ補足情報や関連知識へ進める体験を重視する。
- AI・Googleを意識した設計: 人にも検索エンジンにも内容と役割が伝わる見出し、文章、構造を整備する。
- 目指す方向: 利用者が毎日の疑問を迷わず解決でき、必要に応じて関連ツールやゴマ知識へ自然に移動できるサービスを目指す。

- インデックス未登録の場合は、noindex、robots、canonical、リンク導線、内容重複を確認する。
- 一時的な未登録や順位変動だけを理由に、URLやSEO設定を頻繁に変更しない。
- 検索クエリを確認できない場合は推測で本文やSEOを変更せず、確認できた実データの範囲だけで改善する。

## 17. Analytics

- Google Analytics 4を導入済み。
- `gtag.js`を直接埋め込み、sitemap掲載75ページで各1回読み込んでいる。Google Tag Managerと独自イベントは未使用。
- ツール入力値・生成結果・計算式をAnalyticsイベントへ送る処理は確認されていない。
- Cookie同意バナー、Consent Mode、開発環境の除外処理は確認されていない。
- 基本確認頻度: 週1回を目安とし、新規公開や大きな改善の後にも確認する。
- 主に見る項目: 利用者数、人気ページ、流入経路。
- 必要に応じてセッション、表示回数、ランディングページ、エンゲージメント、利用端末も確認する。
- 急な増減があった場合は、計測漏れ、参照元、対象ページ、Search Consoleの状況をあわせて確認する。
- 現在の実測値、拡張計測、内部トラフィック除外、データ保持はAnalytics管理画面で要確認。

### 入口ページ育成レビュー

Search Consoleでインデックス登録、検索表示、検索流入を確認したページや、Analyticsで利用者が多いページは、`docs/index-page-growth-review-spec.md`を標準テンプレートとして継続的にレビューする。

レビューでは次を確認する。

- 主要情報へ短時間で到達できるか
- 利用者が結果確認後に行う可能性の高い次の行動
- 関連ツール、ゴマ知識、ゴマ早見表の関連性
- ブランド表現、スマートフォン表示、アクセシビリティ
- Search Consoleの検索クエリ、表示回数、クリック数、平均掲載順位との整合性

標準テンプレートには、利用者の次の行動、実装時点で公開状況を確認するレビュー候補、Search Consoleデータとの整合性、レビュー結果の記録を含める。結果には、実施した改善だけでなく、検討の上で見送った改善、見送った理由、必要に応じて再検討条件も残し、「未対応」と「変更不要」を区別する。

現在の基本運営サイクル:

1. 新しいページを公開する
2. 必要に応じてインデックス登録をリクエストする
3. Search ConsoleとAnalyticsで状況を確認する
4. 検索クエリ、表示回数、クリック数、平均掲載順位、利用状況を確認する
5. 標準テンプレートで入口ページ育成レビューを行う
6. 利用者価値へつながる改善だけを実施する
7. 経過観察し、必要に応じて再レビューする

レビュー完了済みは、ホーム・ブランド改善、和暦・西暦変換、年齢・日付計算、パーセント計算、ガソリン代計算。今後はBMI計算、文字数カウント、電卓、今日の情報などで検索表示・検索流入を確認できた時点に、実データをもとに優先順位を決める。

「こんなときはこちら」のような利用シーン別導線は保留とする。Search Console・Analyticsのデータから必要性を確認できるまでは、現在の関連コンテンツ構成を維持する。
